# ManeFlow Roadmap

1. Release the guided Collection Survey as an owner/private-beta feature.
2. Connect visible survey crops to the existing card-identification pipeline.
3. Create an authorized labeled environment dataset and benchmark split.
4. Train storage, stack, binder, slab, sealed-product, supply, and non-inventory detection.
5. Add feature-matching and camera-pose-assisted multi-view deduplication.
6. Add representative sampling and completed-sale-backed valuation tiers.
7. Implement survey reports and acquisition exports.
8. Complete Showcase Price Review and Deal Evaluation approval queues.
9. Integrate Meta intake only after authentication, consent, provider approval, and E2E testing.
