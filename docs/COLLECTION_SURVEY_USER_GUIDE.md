# Collection Survey User Guide

1. Open **Survey**.
2. Choose the survey type.
3. Add one wide image and overlapping close-ups.
4. Review darkness, blur/detail, and resolution warnings.
5. Add visible boxes, binders, slabs, stacks, sealed products, and non-inventory objects.
6. Confirm fullness and content type only when known.
7. Use the same stable label for the same object in repeated views; ManeFlow flags it as a possible duplicate.
8. Generate the estimate.
9. Review low, expected, high, confidence, assumptions, hidden areas, and next-photo guidance.
10. Save the survey for human review.
