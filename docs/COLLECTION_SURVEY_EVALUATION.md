# Collection Survey Evaluation

Current automated tests verify conservative ranges, non-inventory exclusion, duplicate-key double-count prevention, and user-scoped persistence/auditing. These tests do not establish real-world counting accuracy.

A production detector release requires labeled benchmarks for container classification, direct count, stack height, fullness, duplicate views, hidden areas, and count-range coverage. Results must report absolute error, percentage error, calibration, and P50/P95 latency.
