# Authenticated Meta browser execution boundary

The ManeFlow repository can define and test the callback, signature validation, owner isolation, approval workflow, provider client, and fail-closed configuration. It cannot prove or perform authenticated Meta dashboard actions from source control or CI.

The following remain owner-session actions:

- linking the exact Facebook Page and Instagram professional account;
- entering the callback and verification token;
- selecting webhook subscriptions and permissions;
- configuring OAuth redirect URIs and app domains;
- completing Business Verification and App Review;
- creating or rotating access tokens;
- moving the Meta app from development to live;
- sending real permitted test events and inspecting Meta delivery diagnostics.

Do not treat an open browser tab as evidence that any action is completed. Record direct evidence after each change without exposing credentials.
