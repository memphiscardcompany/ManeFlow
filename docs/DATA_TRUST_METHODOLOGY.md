# Data Trust Methodology

ManeFlow values are calculated from included, source-labeled, comp-quality-scored completed sales.

## Sale Requirements

A sale must have:

- completed-sale status
- valid all-in price
- valid sale date
- non-future sale date
- authorized source basis
- acceptable data-rights status
- sufficient card-match confidence

## Exclusions

ManeFlow excludes or quarantines:

- active listings
- missing prices
- missing sale dates
- future sales
- wrong cards
- wrong grades
- wrong parallels
- duplicate sales
- IQR outliers
- demo comps in production mode
- unverified or not-for-public-value data rights

## User Transparency

Public-safe comp summaries include provider, sale type, date, all-in price, source badge, quality score, inclusion status, reasons, warnings, and explanation.

Raw provider payloads, credentials, private seller data, and customer data are not exposed publicly.
