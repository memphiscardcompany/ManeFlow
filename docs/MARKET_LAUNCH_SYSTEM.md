# ManeFlow v1.6 Market Launch System

v1.6 moves ManeFlow from a single-business product package toward a multi-platform launch system:

- iOS/Android Expo app readiness
- secure desktop shell
- multi-shop organization model
- website embed kit
- scan confidence pipeline
- merchant pricing center
- bulk intake/show mode
- provider import-job controls

The system remains solo-founder maintainable: no heavy frontend rewrite, no hidden credentials, no unauthorized scraping, and no claims of live market coverage without approved data rights.

## Launch posture

ManeFlow can run locally and support controlled demos/betas immediately. Public pricing claims require production deployment and authorized completed-sale data.
