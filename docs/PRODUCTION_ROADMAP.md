# Production roadmap after v1.2

## Gate 1 — controlled licensed beta

- Sign the first completed-sale data agreement.
- Load the first rights-cleared comprehensive catalog.
- Deploy the included release behind HTTPS.
- Configure production image understanding.
- Move persistent data to managed PostgreSQL before multi-instance deployment.
- Add email verification and password reset.
- Complete security, privacy, and legal review.
- Ship internal Android/iOS builds and run a closed collector/merchant beta.
- Measure exact-card match rate, correction rate, latency, comp coverage, and retention.

## Gate 2 — public collector launch

- Add background watch evaluation and push notifications.
- Add account deletion and automated privacy export.
- Add subscription billing and entitlement enforcement if premium plans launch.
- Expand catalog coverage and rights-cleared card imagery.
- Add grading-cert verification through approved grader integrations.
- Add correction workflows and comp dispute review.
- Add production analytics, support tooling, status page, backups, and incident response.

## Gate 3 — merchant platform

- Merchant organizations, staff roles, and locations
- Inventory intake, offers, buy lists, grading, consignment, and sale-state workflows
- Authorized marketplace listing submission
- Merchant API keys, quotas, webhooks, and usage metering
- Batch scans and high-volume imports
- Pricing rules by fee, margin, liquidity, and aging
- POS, ecommerce, inventory, and accounting integrations

## Gate 4 — definitive intelligence network

- Multiple independent licensed completed-sale sources
- Near-real-time provider workers with freshness SLOs
- Specialized image retrieval and card-parallel classification
- Regional and marketplace-specific pricing
- Population, scarcity, and demand context from authorized data
- Fraud/anomaly detection and comp-quality review
- International currency, tax, and market support
