# ManeFlow 2.22.0-beta.1 Consolidated Private Beta Report

## Release position

This build combines the strongest accessible ManeFlow Windows, web, mobile, vision, provider, database, and shop-operation code into one private-beta package. It adds zero-input any-order photo grouping and a rights-gated adaptive-learning monitor.

It is not represented as a universal trained card-recognition model, a complete million-card catalog, a signed public Windows release, or a store-approved application.

## Learning completed

- 20 owner-authorized images prepared
- Self-supervised synthetic-view grouping calibration completed
- 80 positive transformed-view pairs and 190 negative cross-image pairs evaluated
- Generated-pair calibration result: 98.75% true-positive rate and 0% false-positive rate
- No user-entered card labels used
- No neural model weights changed
- No unverified exact identity entered reference memory

## Active safeguards

- Empty and unchanged training cycles are skipped
- eBay and other marketplace images are excluded from training
- Noncommercial images cannot enter commercial reference memory
- Filenames and upload order cannot determine card identity
- Exact results require corroborated evidence
- Model promotion requires verified labels, an external trainer, and a locked benchmark

- Human-audited benchmark results at meaningful scale
- Managed PostgreSQL and physical hardware validation
